Open browser Console (F12) for full detail.
If you see "✅ EVENT SENT" above, the tracker is working.
If nothing appears, check Console for errors.

Common fixes:

  • CORS error → Supabase anon key wrong or table doesn't exist
  • ipapi.co blocked → site has strict CSP (add ipapi.co to connect-src)
  • No events → debounce bug (now fixed in latest tracker.js)
  • Rate limited → ipapi.co free tier = 1,000 req/day
